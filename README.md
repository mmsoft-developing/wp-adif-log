# ADIF Log – WordPress plugin

Displays a searchable QSO log table from an ADIF (`.adi` / `.adif`) file uploaded to the WordPress media library. Comes in two flavours, each available as a **Gutenberg block** and as an **Elementor widget**:

- **ADIF POTA log** – for POTA activations, with a park-to-park column
- **ADIF Contest log** – for contests, with a country column and a list of worked countries

Made by HA8AI, works with any ADIF export (Ham2K Portable Logger, DXLog.net, LoTW reports, etc.).

## Features

- Columns of the **ADIF POTA log**: `# · Date · Time (UTC) · Callsign · Frequency · Mode · RST (S/R) · P2P`
  - park-to-park contacts show the other park reference as a badge (e.g. `FR-2795`)
  - automatic title (“HA8AI POTA Log” / “HA8AI Log”) and location (park reference and name) from the ADIF file
- Columns of the **ADIF Contest log**: `# · Date · Time (UTC) · Callsign · Frequency · Mode · RST (S/R) · Country`
  - the country (DXCC entity) comes from the `DXCC` or `COUNTRY` field, or – if neither is present – from the callsign prefix (based on [AD1C’s Big CTY](https://www.country-files.com/) data)
  - country summary bar: the number of different countries worked; click it to expand the alphabetical list of countries in the selected language, each with its QSO count (e.g. “Germany (25)”)
  - automatic title (“HA8AI Contest Log”), the contest name (`CONTEST_ID`) is shown under it
- Columns that are empty in the whole file are hidden automatically
- QSOs are always sorted by date and time
- Title and location can be overridden
- Summary bar: QSO count, bands, modes (optional)
- Instant search field (optional)
- Compact mobile layout
- Interface and country-name languages: English, Hungarian, German, French, Spanish, Italian – selectable per block/widget, defaults to the site language

## Requirements

- WordPress 6.3 or newer
- PHP 7.4 or newer
- Elementor (optional, only for the widgets)

## Installation

1. Download `adif-log.zip` from the [latest release](https://github.com/mmsoft-developing/wp-adif-log/releases/latest).
2. In WordPress: **Plugins → Add New → Upload Plugin**, choose the ZIP, then activate.

## Usage

1. Upload your `.adi` / `.adif` file to the media library.
2. Add the **ADIF POTA log** or **ADIF Contest log** block (Gutenberg) or widget (Elementor) to a page.
3. Select the file. Optionally set the title, location, language, and turn the summary bars or the search field on/off.

## Updating the country data

The country tables (`adif-log/languages/countries/*.php`, `adif-log/includes/dxcc-prefixes.php`) are generated by `tools/dxcc/generate.php` from the current `cty.csv` – see the comment at the top of that script.
